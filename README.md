# Miel de Castillo 🍯

Tienda online estática para Miel de Castillo, proyecto familiar de miel artesanal de l'Alcora (Castellón).

## Publicación con GitHub Pages
1. Entra en **Settings → Pages**.
2. En **Build and deployment**, selecciona **Deploy from a branch**.
3. Elige la rama `main` y la carpeta `/ (root)`, guarda y espera a que finalice la publicación.

## Antes de aceptar pedidos reales
- Sustituir el logo vectorial provisional por el archivo oficial de marca.
- Confirmar precios, disponibilidad y características de cada variedad.
- Añadir datos legales del vendedor, privacidad, cookies, condiciones de compra y devoluciones.
- Configurar pagos seguros, cálculo de envío, pedidos y confirmaciones. El carrito actual es solo de demostración y no cobra.
- Reemplazar el correo de contacto de ejemplo por el correo real.

La web utiliza HTML, CSS y JavaScript sin dependencias de compilación.
